# SentinelIQ — OSINT Intelligence System

AI-powered OSINT-style claim verification system using NLP embeddings, semantic similarity scoring, and source credibility weighting.

## Features

- News claim verification
- Semantic similarity scoring
- Source credibility weighting
- Intelligence-style evidence reports
- FastAPI backend
- Streamlit frontend dashboard

## Tech Stack

- Python
- FastAPI
- Streamlit
- Sentence Transformers
- NewsAPI
- NLP Embeddings

## Example Claims

- "Students were kidnapped in northern Nigeria"
- "5G towers spread COVID-19"
- "The moon landing was faked"

## Disclaimer

This system performs evidence correlation and credibility-weighted semantic analysis. It does not represent absolute truth verification.
